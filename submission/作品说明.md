## 二、作品简介

这是一个“不只告诉你走哪里，还告诉你为什么”的教学式 3D 国际象棋。

它保留标准国际象棋规则和 3D 木质棋盘，但把重点放在**新手能不能看懂**：选中棋子后，棋盘只画与它相关的威胁、保护和可吃关系；悬停一个落点，会推演“你走 → 对方最可能怎么应 → 你接下来怎么走”，如果这一步会送子，就用中文直接说“对方会用车吃掉你的后，你将损失 9 分”。此外还有教学 AI、四档难度、大局观提示、2D 备用棋盘、PeerJS 点对点联机和标准 PGN 棋谱导出。

## 三、想解决什么问题

很多国际象棋软件对新手并不友好：

- 合法走法画出来了，但新手不知道哪一步会丢子；
- 引擎给出 `+1.2`、`-3.4` 这样的分数，新手看不懂；
- 威胁、保护、牵制关系藏在脑子里，棋盘上没有任何提示；
- 想复盘时，找不到简单、标准的棋谱导出方式。

本作品把“规则正确”作为底线，把“教学解释”作为核心：所有判断都从 `chess.js` 的合法局面出发，再由攻击图、SEE、轻量引擎和中文文案层层翻译成新手能理解的话。

## 四、核心功能

### 1. 教学式多步推演（Step 5）

- 选中己方棋子后，悬停任意合法落点，面板展示“你走 → 对方最可能应招 → 你下一步”的三层推演；
- 棋盘上用金色箭头表示推荐，用半透明红色箭头表示对方最可能应招；
- 用独立 Web Worker 计算，260ms 防抖 + 缓存，不阻塞拖拽和落子。

### 2. 送子警告

- 引擎先算当前局面最佳分，再强制走候选着法，让对手走最佳应招；
- 用“最佳分 − 候选分”衡量损失；
- 明显掉分时棋盘下方出现红色警告条，直接说清“对方用哪个棋子、吃掉你的哪个棋子、损失多少分”；
- 轻微掉分用黄色“注意”，明显送子用红色“危险”。

### 3. 威胁 / 保护 / 可吃连线

- 只在选中棋子时出现，最多 3 条，避免糊屏；
- 红线 = 威胁，绿线 = 保护，金线 = 可吃；
- 基于合法攻击图与 SEE，不用“控制格”冒充“真威胁”；
- 点击敌方棋子，也能看它正在威胁我的哪些棋子。

### 4. 虚影走法预测

- 鼠标悬停合法落点，出现半透明虚影棋子；
- 在虚影局面上继续画“走后”的威胁、保护、可吃虚线；
- 让新手在落子前就能看到“走完这一步，局面会变成什么样”。

### 5. 教学 AI 与大局观

- 四档难度、执白/执黑、评估条；
- 每步 AI 解析：发展棋子、占据中心、王的安全、空间优势；
- 推荐卡给出最佳 + 1–2 个备选，附中文理由与风险等级。

### 6. 标准 PGN 棋谱导出

- 走子历史区新增“导出棋谱”按钮；
- 导出标准 PGN：`Event`、`Site`、`Date`、`Round`、`White`、`Black`、`Result`，movetext 使用 chess.js 的 SAN；
- 白/黑方名称按双人同屏、教学 AI、联机三种模式自动生成；
- 结果为白胜 `1-0`、黑胜 `0-1`、和棋 `1/2-1/2`、未结束 `*`；
- 纯前端 Blob 下载，不引入新依赖；文件名为 `chess-YYYYMMDD-HHmm.pgn`。

### 7. 其他

- 3D 木质棋盘、GLB 棋子、吃子倒地、Web Audio 音效；
- 2D 备用棋盘；WebGL 不可用或上下文丢失时自动回退；
- 手机触屏两次点按确认落子，无遮挡提示；
- PeerJS P2P 联机：6 位房间号、房主权威校验、悔棋/重开同步；
- 显示设置 4 个独立开关：推荐、威胁/保护箭头、虚影推演、右侧提示栏。

## 六、技术方案

| 层 | 方案 |
|---|---|
| 前端框架 | Vite 7 + React 19 + TypeScript 5 |
| 3D 渲染 | Three.js r186；GLB 棋子 + 程序化木纹 + 自定义箭头/连线 |
| 规则内核 | chess.js 1.4；`GameController` 是唯一规则真源，UI/3D/AI 不能自行判定合法性 |
| 引擎 | 独立 Web Worker 中的轻量 alpha-beta 搜索引擎，支持 MultiPV、候选推演 |
| 分析 | 合法攻击图、SEE、威胁等级、保护关系、战略维度 |
| 联机 | PeerJS DataChannel；房主权威全量状态同步（FEN + 走子记录） |
| 导出 | `src/domain/pgn.ts` 生成 PGN，`src/ui/download.ts` 用 Blob + `<a download>` 下载 |
| 部署 | Netlify 静态构建；`netlify.toml` 固定 Node 22 |

### 关键设计

- **规则不分叉**：所有走子都经过 `GameController`，预览用 `previewFen()` 在 chess.js 的克隆局面上试走，避免 UI 自己拼规则。
- **教学分层**：引擎分数 → 攻击图/SEE → 中文解释，三层各自可测试。
- **不阻塞交互**：引擎在 Worker 中运行，候选推演带防抖和缓存。
- **可回退**：3D 初始化失败或 WebGL 上下文丢失时自动切 2D，页面不白屏。

## 八、创新点

1. **教学优先，而不是引擎优先**：把引擎分数翻译成“会丢哪个子、丢多少分”的具体句子。
2. **多步推演 + 虚影 + 箭头三件套**：新手在同一屏看到“我走、对方应、我再走”的完整因果链。
3. **只画相关关系**：威胁/保护最多 3 条，避免把棋盘画成蜘蛛网。
4. **真实可复盘的导出**：标准 PGN，能直接导入 Lichess/Chess.com 等工具继续分析。
5. **纯前端、零后端**：规则、引擎、导出、联机信令都在浏览器完成，部署成本低。

## 九、已知限制

- 推演只到“你 → 对方 → 你”三层，不是完整变着树；
- 教学引擎是深度 2 的轻量引擎，不是 Stockfish；
- 联机依赖 PeerJS 公共信令；断线重连、TURN、房间密码暂未实现；
- PGN 只导出标准七标签，不含注释、变着和时钟；
- 3D 模型来自 Pia Leung（CC BY 3.0），详见 `public/models/ATTRIBUTION.md`。
